# Удалённый агент по SSH

Агент (Claude Code, Codex и т. п.) работает на **другом компьютере**, а панель — на сервере. Панель в сеть не открывается.

1. На сервере откройте страницу **Подключение агентов** → зарегистрируйте агента → блок **Удалённое подключение → SSH**. Если SSH-сервер выключен, панель подскажет, как его включить (на Mac — «Удалённый вход»).
2. Выберите агента. На компьютере агента выполните показанную команду `ssh-keygen` — это отдельный ключ только для этого агента.
3. Вставьте содержимое файла `.pub` в поле и нажмите **Собрать строку**. Добавьте полученную строку одной строкой в `~/.ssh/authorized_keys` на сервере. Панель файл сама не меняет.
4. На компьютере агента выполните показанную команду `claude mcp add …` (или вставьте JSON в настройки клиента).

Ключ умеет **только** запускать мост MCP этого агента: нет оболочки, нет проброса портов, секрет агента не покидает сервер. Права агента (L1/L2/L3) и подтверждения изменений остаются на сервере, как и при локальной работе.

Отзыв: удалите строку из `authorized_keys` или отзовите агента на странице.
