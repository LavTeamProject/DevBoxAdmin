# Подключение агентов: разделы и мастера

Страница **Подключение агентов** разделена на части, а типовые задачи сделаны мастерами (кнопка «Начать» на «Обзоре»).

## Разделы
- **Обзор** — состояние (агенты, подтверждения, Telegram, API, операторы), три мастера и объяснение, **где вы одобряете действия**.
- **Агенты** — таблица агентов, уровни, ротация и отзыв секрета.
- **Подтверждения** — планы, которые предложили агенты, и режим одобрения.
- **Операторы** — администраторы, которые смотрят состояние и одобряют планы удалённо: права, Telegram-чат, секрет TOTP.
- **Каналы** — тонкая настройка SSH, API и Telegram-бота.
- **Каталог операций** — что вообще умеет панель и что доступно агентам.

## Мастера
1. **Подключить ИИ-агента** — имя и уровень (L1 чтение / L2 предлагает изменения / L3 + CI) → где работает агент (этот компьютер, другой по SSH, своё приложение по API) → готовая команда или инструкция.
2. **Управлять через Telegram** — токен вашего бота (создаётся у @BotFather) → **оператор** (бот слушает только операторов: мастер предлагает создать первого или выбрать существующего; ваш чат определяется сам: напишите боту любое сообщение, чат появится в списке) → секрет TOTP для приложения-аутентификатора и включение одобрения из Telegram → проверка командой `/status`.
3. **Подключить своё приложение (API)** — откуда обращаться (только этот компьютер / сеть или VPN с TLS и списком адресов / свой вариант) → токен оператора или агента → адрес, отпечаток сертификата и пример запроса.

## Где вы одобряете действия
- **Планы агентов L2.** Агент сам ничего не меняет, он предлагает план. Вы нажимаете «Одобрить» на странице «Подтверждения» — тогда на этом компьютере открывается системное окно. Если настроены Telegram-оператор и включено «Операторы могут одобрять планы», план можно одобрить в Telegram (команда `/approve <id> <хеш> <код>`, код из аутентификатора): окно на компьютере тогда не нужно.
- **Операции L3 (CI).** Только системное окно на этом компьютере. Из Telegram и API их одобрить нельзя.
- **Настройки на этой странице**, которые ослабляют защиту (подключить бота, оператор с правом одобрения, удалённый доступ, поднять уровень агента, выдать токен): всегда системное окно на этом компьютере. Telegram его не заменяет.
- Сам агент ничего одобрить не может.
