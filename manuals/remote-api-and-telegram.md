# Удалённый API, операторы и Telegram-бот

Страница **AI-доступ → Удалённое подключение**. Всё выключено по умолчанию. Любое включение и расширение доступа подтверждается **системным окном на машине с панелью** (на Linux без экрана — `service-admin approve`, см. `connect-ai-agent-linux.md`).

## 1. API для своего приложения
1. Блок **API для своего приложения**: адрес (127.0.0.1 — для обратного прокси/SSH-туннеля; адрес LAN/VPN; вне localhost обязательны **TLS** и **список разрешённых адресов**), порт (по умолчанию 8766), «Включить» → **Сохранить** → подтвердите в системном окне.
2. Панель покажет адрес и **отпечаток сертификата SHA-256**: закрепите его в клиенте (пример — `examples/remote_client.py`, описание — `docs/openapi-remote.yaml`).
3. Токен агента для клиента: выберите агента → **Выдать новый токен** (прежний перестанет работать). Токен показывается один раз.

## 2. Операторы
Оператор — администратор: смотрит состояние/журнал и одобряет планы **L2**. Создайте: имя, права (чтение / одобрение), при желании Telegram `chat_id`. Токен и секрет TOTP показываются **один раз**: добавьте секрет в приложение-аутентификатор. Оператор с правом одобрения создаётся через системное окно. Одобрение требует: токен, **одноразовый код TOTP**, **хеш плана** и включённой настройки «Операторы могут одобрять планы». План **L3** удалённо одобрить нельзя.

## 3. Telegram-бот
1. Создайте бота у @BotFather, вставьте его токен в блок **Telegram-бот**, «Включить» → **Сохранить** (системное окно) → **Проверить токен**.
2. Напишите боту `/start`: он ответит вашим `chat_id` — впишите его оператору.
3. Команды: `/status`, `/plans`, `/approve <id> <хеш> <код>`, `/reject <id>`. О новых планах бот сообщает сам.
Бот сам опрашивает Telegram (входящий порт не нужен). Сообщения идут через серверы Telegram и содержат краткое описание плана без секретов.

Отзыв доступа: «Отозвать» у оператора; выключить API — снять «Включить» (без диалога).
