# Python и пакеты Homebrew

## Python (Языки → Python)
- **Установленные версии**: все найденные Python (uv, Homebrew, pyenv, python.org, системный). «Сделать по умолчанию» создаёт ссылки `python`, `python3`, `pip`, `pip3` в `~/.service-admin/bin` и (один раз) блок в `~/.zshrc`, ставящий эту папку в начало PATH. После этого `python3` работает **без полного пути**; в открытых терминалах выполните `hash -r` или откройте новое окно. «Сбросить выбор» возвращает порядок PATH.
- **Установить версию Python**: 3.10–3.14 через uv (в вашу папку, без прав администратора) или Homebrew (`python@X.Y`). Версии ставятся рядом и ничего не меняют по умолчанию.
- **Удалить версию**: кнопка у версий, поставленных uv, Homebrew или pyenv. Нельзя удалить Python по умолчанию, тот, на котором работает панель, версию python.org и системный Python Apple.
- **Пакеты pip**: выберите Python в списке, смотрите, ставьте (`pip install`) и удаляйте пакеты. pip, setuptools и wheel защищены. Для Python, защищённых PEP 668 (Homebrew), панель советует pipx или виртуальное окружение.

## Пакеты Homebrew (Пакеты и сервисы)
- Фильтры: **Все установленные**, **Поставлены вами**, **Зависимости**, **Лишние**, CLI, Приложения, Есть обновления, Сервисы.
- У каждого пакета видно, откуда он (вручную / зависимость / приложение), **кому нужен** и сколько занимает. Сортировка по размеру помогает найти крупное.
- **Лишние** — зависимости, которые больше никому не нужны. «Удалить лишние» выполняет `brew autoremove` после подтверждения со списком. Пакет, нужный другим, кнопки «Удалить» не имеет.
- «Очистить кэш и старые версии» — `brew cleanup`.
